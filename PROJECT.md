# Project

`flyto2` is a deprecated legacy shell for Flyto2 download and security-policy
metadata.

It is not the active product monorepo and is not the source of truth for any
Flyto2 product line.

## Product Line Mapping

- Cloud / Apps / Automation: legacy distribution pointer only.
- Security: security policy contact surface only.
- Data: no implementation.
- Zero-person Company Agent: no implementation.
- Big Data / Intelligence: no implementation.

## Role

Keep this repository understandable for users who arrive through old releases,
old links, or security disclosure paths. Direct active engineering work to the
correct Flyto2 repository.
