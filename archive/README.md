These documents are archived because:
1. **One-time reports** - Implementation summaries, audits (not living docs)
2. **Superseded content** - Information now in main documentation
3. **Internal records** - Development notes, not user-facing
4. **Very niche** - Applicable to <5% of users
5. **Language issues** - Chinese docs in English project
