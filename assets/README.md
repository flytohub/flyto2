# Flyto2 Assets

This directory contains brand assets for Flyto2.

## Logo Files

Please add your logo files here:

### Required Files
- `logo.svg` - Main logo (vector format, recommended)
- `logo.png` - PNG fallback (transparent background)
- `architecture.svg` - Architecture diagram showing Engine/UI separation

### Recommended Sizes
- **512x512** - GitHub repository avatar
- **256x256** - Documentation headers
- **64x64** - Favicon

## Usage

The logo is used in:
- README.md header
- Documentation pages
- GitHub repository settings
- Social media profiles

## File Specifications

### SVG (Recommended)
- Format: SVG 1.1
- Transparent background
- Single color or gradient
- Optimized with SVGO

### PNG (Fallback)
- Format: PNG-24
- Transparent background
- High resolution for scaling

## Brand Guidelines

- Primary color: Purple/Violet (as shown in logo)
- Use on light or dark backgrounds
- Maintain aspect ratio when resizing
- Minimum size: 32x32 pixels

---

To add the logo, simply place your logo.svg file in this directory.
