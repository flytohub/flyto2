# Supported Legacy Surfaces

## Active Repository Routing

The README directs users who arrive through old links to the current Flyto2
runtime, cloud, security, code-intelligence, documentation, and website owners.
It is a discovery surface only and does not duplicate their installation or API
documentation.

## Historical Release Discovery

The GitHub Releases link preserves access to artifacts that may have been
published from this repository. The release page, its checksums, and its notes
are authoritative. This checkout does not build, sign, test, or publish a
desktop binary.

## Security Disclosure Routing

`SECURITY.md` sends private vulnerability reports to `security@flyto2.com` and
defines the information reporters should include. It does not claim that this
legacy shell receives fixes for vulnerabilities owned by active repositories.

## Project Memory

The root memory files preserve the deprecation decision, repository boundary,
maintenance state, and contributor workflow. They prevent automated agents or
new contributors from reintroducing active product code here.

## Verification Contract

The local workflow lints repository text, tests required routing and security
documents, builds a deterministic archive of public documentation, and runs
strict Flyto2 Indexer verification. It intentionally has no application build,
release publication, or deployment authority.
