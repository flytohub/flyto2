# Repository and Source Routing

Use the narrowest owner for implementation work. Use `flytohub/flyto2` only for distribution contracts, release evidence, promotion, and download metadata.

| Need | Source of truth |
| --- | --- |
| Flyto2 Flow product source | [flyto-flow](https://github.com/flytohub/flyto-flow) |
| Flyto2 Runtime product source | [flyto-runtime](https://github.com/flytohub/flyto-runtime) |
| Flyto2 Agent Firewall source/backend/connectors | [flyto-engine](https://github.com/flytohub/flyto-engine) |
| Shared execution/browser automation primitives | [flyto-core](https://github.com/flytohub/flyto-core) |
| Hosted Cloud product | [flyto-cloud](https://github.com/flytohub/flyto-cloud) |
| Security UI/product workflows | [flyto-code](https://github.com/flytohub/flyto-code) |
| Repository intelligence and impact analysis | [flyto-indexer](https://github.com/flytohub/flyto-indexer) |
| Public technical documentation | [flyto-docs](https://github.com/flytohub/flyto-docs) |
| Public website and download entry point | [flyto2.com](https://flyto2.com) |
| Public technical articles | [blog.flyto2.com](https://blog.flyto2.com) |
| Product catalog, official release metadata, SBOM/provenance policy, release channels | **this repository** |

Historical `v0.x` GitHub Releases in this repository are the pre-rename Flyto2 Flow lineage. Preserve their tags and assets.

Security reports go to `security@flyto2.com`.
