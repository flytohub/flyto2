# Flyto2 Agent Firewall

[← Back to Flyto2 Distribution Hub](../../README.md)

Flyto2 Agent Firewall is the endpoint, MCP, browser, and enterprise connector suite for AI/agent activity enforcement and evidence.

## Downloads

No Agent Firewall build has been promoted through the Flyto2 Distribution Hub yet.

The implementation repository already owns the connector build/release pipeline. Private/internal source-repository details are intentionally not published from this public distribution repository.

The Distribution Hub will become the public product-specific release entry point after candidate ingest and promotion are wired.

## Release namespace

Future Distribution Hub releases use:

```text
agent-firewall/vX.Y.Z
```

The stable/beta channel files below remain product-specific and must never resolve through the repository-wide `/releases/latest` alias.
