# Investigation

Investigation checklist:

- Identify the product id, version, distribution tag, and source repository.
- Compare the release manifest, source commit, build run, artifact digest, SBOM, provenance, and signing evidence.
- Check whether the problem is distribution metadata or product behavior.
- Preserve historical and published release identities while investigating.
- Check README, product registry, release policy, and channel metadata for drift.
- Record durable findings in `handoffs/`.

Product behavior belongs to the owning source repository.
